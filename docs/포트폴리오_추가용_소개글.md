# 포트폴리오 소개글

개인 관심사(게임 시세·공지, 암호화폐, 환율, 서비스 상태)를 한 화면에서 확인할 수 있는 Next.js 실시간 정보판에 데이터 신선도 배지를 추가했습니다. 정상 수신은 `fresh`, 장애 후 마지막 정상값을 유지하는 상태는 `stale`, 최초 데이터조차 없는 상태는 `unavailable`로 구분하고 마지막 수신 시각과 경과 초를 함께 표시해 사용자가 데이터의 현재성을 바로 판단할 수 있습니다.

기존 외부 API·DB 계층은 건드리지 않고 클라이언트의 공통 실패 처리와 1초 클록을 재사용했습니다. `?simulate=timeout|auth|ratelimit|empty`로 장애를 재현하며, 색상뿐 아니라 텍스트와 `aria-label`로 상태를 전달합니다. Vitest 45개와 Playwright E2E 14개가 통과했고, 사전에 고정한 T05 검사 10개를 모두 충족했습니다.

작업은 AI A 구현·7항목 인수인계·AI B 완성의 두 단계로 나눠 진행했습니다. 시작·인계·완료 커밋과 작업 시간, 프롬프트 수, 실패 회차를 기록해 AI 간 인계의 재현성과 결과 품질을 비교할 수 있게 했습니다.
