# T05 고정 검사 및 공통 상한 (작업 전 고정 · 변경 금지)

> 이 문서는 과제 5의 **동결(frozen) 계약**이다.
> AI A, AI B 누구도 이 파일의 검사 문구·기대값·상한을 삭제하거나 완화하거나 바꾸지 않는다.
> 출처: `../../과제5_템플릿/01_고정검사_및_상한.md` (2026-08-28 고정).

## 1. 개선 대상 기능

- **선택 프로젝트**: 과제 4 실시간 정보판 (`realtime-info-board-t04`)
- **개선 내용**: 실시간 데이터의 신선도 상태를 화면에서 바로 알 수 있도록
  상태 배지(`fresh` / `stale` / `unavailable`)와 텍스트 기반 마지막 갱신 시각·경과 시간(`ageSeconds`) UI를 추가한다.
- **선언 기능은 정확히 1개**: "데이터 신선도 상태 배지 + 장애 재현 시 상태 갱신".

## 2. 공통 사용 상한 (AI A · AI B 공통, 작업 전 고정)

| 항목 | 상한 |
|---|---|
| 세션당 작업 시간 | **최대 15분** |
| 세션당 프롬프트 / 호출 수 | **최대 10회** |

- 상한은 AI A 시작 전에 고정되었다. AI A·AI B 모두 동일 상한을 적용한다.
- 각 세션은 실제 작업 시간과 실제 프롬프트 수를 `docs/04_작업_기록.md`에 기록한다.

## 3. 고정 검사 10개 (T05-C01 ~ T05-C10)

| ID | 검사 입력 (사용자 행동) | 기대값 (관찰 가능한 결과) |
|---|---|---|
| T05-C01 | 앱 접속 후 정상 데이터 수신 시 화면 상단 상태 배지 확인 | "fresh" 텍스트와 초록색 안정 아이콘이 함께 표시된다. |
| T05-C02 | 데이터 경과 시간(ageSeconds) 렌더링 확인 | 상태 배지 옆에 마지막 정상 수신 시각과 경과 시간(ageSeconds)이 숫자로 표시된다. |
| T05-C03 | 브라우저에서 `?simulate=timeout` (타임아웃 장애) 주소로 접속 | 이전 정상 데이터(차트 및 값)가 화면에서 사라지지 않고 유지된다. |
| T05-C04 | 타임아웃 장애 시 상태 배지 문구 확인 | 상태 배지가 "stale" (업데이트 지연) 문구 및 노란색 경고 아이콘으로 변경된다. |
| T05-C05 | 타임아웃 장애 시 시간 갱신 확인 | 갱신 시각이 멈춰 있고, 경과 시간(ageSeconds)이 계속 증가함을 확인할 수 있다. |
| T05-C06 | 브라우저에서 `?simulate=auth` (권한 장애) 주소로 접속 | 상태 배지가 "stale"로 변경되며, 오류(401/403) 원인이 텍스트로 작게 안내된다. |
| T05-C07 | 브라우저에서 `?simulate=ratelimit` (호출 제한) 주소로 접속 | 상태 배지가 "stale"로 변경되며, 다음 갱신을 위해 대기 중이라는 문구가 표시된다. |
| T05-C08 | 브라우저에서 처음부터 빈 DB 상태(데이터 미수신) 장애 재현 | "unavailable" 텍스트와 함께 "데이터를 가져오지 못했습니다"라는 안내가 표시된다. |
| T05-C09 | 색상 외 식별 가능성 검증 (접근성) | 상태 배지의 상태가 색상에만 의존하지 않고, 반드시 텍스트(fresh/stale/unavailable)로 구분 가능하게 렌더링된다. |
| T05-C10 | Playwright E2E 테스트 스크립트 실행 (`npm run test:e2e`) | 추가된 상태 배지(fresh/stale/unavailable) 렌더링에 대한 UI 검증 테스트가 모두 통과(PASS)한다. |

## 4. 동일한 최초 요청 프롬프트 (AI A · AI B 공통)

> "우리는 과제 4번(realtime-info-board-t04)에 데이터 신선도 상태 배지 UI를 추가할 거야.
> 프런트엔드에서 API 응답의 `dataStatus`(fresh, stale, unavailable) 및 `ageSeconds`를 읽어
> 화면 우측 상단에 텍스트와 아이콘이 혼합된 상태 배지를 띄워줘.
> 퍼플렉시티 리서치에 명시된 대로, 에러 시 화면을 지우지 말고
> 마지막 정상값을 유지한 채 배지만 stale로 변경해야 해."
